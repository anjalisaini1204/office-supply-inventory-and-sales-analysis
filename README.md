
# Office Supply Inventory and Sales Analysis

## Project Overview

The **Office Supply Inventory and Sales Analysis** project focuses on exploring sales and inventory-related data to support business performance evaluation and data-driven decision-making.

The project uses Microsoft Excel for dataset storage and Microsoft Power BI for data visualization and reporting.

The objective is to organize business data, explore relevant performance indicators, and develop an interactive reporting solution that can help understand sales performance and inventory-related business questions.

## Project Objectives

- Organize and prepare the available business dataset for analysis.
- Explore sales and inventory-related information.
- Identify relevant business performance indicators.
- Analyze sales performance across available business dimensions.
- Develop interactive Power BI visualizations.
- Present business information in an understandable format to support decision-making.

## Tools and Technologies

## Dataset Description

The repository contains an Excel workbook named `dummy_store.xlsx`.

The dataset is maintained in two folders:

- **raw:** Contains the original dataset.
- **clean_data:** Intended to contain the prepared dataset used for analysis.

The current repository contains identical copies of the workbook in both folders. The cleaning process and any transformations should be documented as they are implemented.

## Project Workflow

The project follows a business intelligence workflow:

### 1. Data Collection
- Identify and organize the available business dataset.
- Maintain the original dataset in the raw data directory.

### 2. Data Preparation
- Review the dataset structure and data types.
- Check for missing values and duplicate records.
- Validate data consistency.
- Apply necessary transformations.
- Maintain the prepared dataset separately from the original data.

### 3. Data Modeling
- Load the prepared dataset into Power BI.
- Examine relationships between relevant tables, if applicable.
- Create an appropriate data model for reporting.

### 4. Data Analysis
Explore the available data to understand business performance and identify useful patterns.

Potential areas of analysis include:

- Sales performance analysis
- Inventory performance analysis
- Product-level performance
- Revenue and quantity trends
- Business performance comparisons
- Identification of potential inventory issues

### 5. Data Visualization
- Develop interactive Power BI reports.
- Present relevant business metrics.
- Use charts, tables, cards and filters to make information easier to understand.
